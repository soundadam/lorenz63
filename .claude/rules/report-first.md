# report.md 是底稿，slides 跟着它

讲解、学习、问答都以 `report/report.md` 为准。推导、物理图像、心算数字先写进 report.md
对应的小节，`report/slides.html` 的文案之后再照着它改。

- 问答里讲清楚的东西写进 report.md 的相应位置；长推导放附录，正文指过去。
- slides 文案可以落后于 report.md，不必逐句同步。发现 slides 里的数或说法与 report 矛盾时顺手改掉。

为什么：用户对着 markdown 学习和讲解，彻底弄懂之后再集中重写 slides。
用户开始专攻 slides、改由 slides 驱动时，这条就该删。
