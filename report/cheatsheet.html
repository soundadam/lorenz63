方程从哪来

绪论 · 第 4–13 页 · 11 分钟PDE 对图带过，板书只写方程、代入、截断
第 5–6 页

对图Ra = gαΔT H³ / (νκ) = 想翻的 ÷ 拦着的

对图Boussinesq → 流函数 ψ 与温度偏离 θ 两条 PDE。只读花括号：平流 · 粘性 · 浮力 · 热扩散 · 搬运背景温度

未知量是函数 → 无穷维

“这组方程从哪来，怎么放进计算机？”

锅里的水底下烧：热的变轻想上去，冷的想下来；粘性 ν 拖住流动，热扩散 κ 抹平温差。Ra 小拦得住，水不动；过了临界值长出一排对流卷。能拧的只有 ΔT，Ra ∝ ΔT，这个旋钮后面叫 ρ。

θ 是实际温度减掉传导直线：水不动 θ = 0，所以 θ 量的是对流本身。

两条 PDE，未知量是函数，要先变成有限个数。

第 7–8 页 · 左栏，全程保留

板书 ẋ =σ(y − x)ẏ =ρx − y − xzż =xy − βz

σ = ν/κ = 10　β = 4/(1+a²) = 8/3　ρ = Ra/Rac = 28

ψ ∝ x · sin kX sin πZ　　θ ∝ y · cos kX sin πZ − z · sin 2πZ

x 卷转速（正负是转向）· y 升降流温差 · z 剖面弯曲，Nu = 1 + 2z/ρ

线方法：先空间离散、再时间推进，和声学 FDTD 一样；只是第 1 步用 Fourier 模态，只留 3 个，N = 3，小到每一步都看得清。

大写 X、Z 是坐标，小写 x、y、z 是只随时间变的振幅（H = 1，k = πa）。z 的模态只随竖直 Z 变：中段被搅匀拉平、近板变陡，所以 z 就是对流多运走的热。

x 是转速，y 是温差，z 是多运的热。

第 9 页 · 代入几项

板书Galerkin：代进 PDE → 乘每个模态 → 在一个卷上积分。线性项各回各的模态，只看平流 J(a, b) = u·∇b：

  • ① 卷 × 卷　J(ψ, ∇²ψ) = 0（∇²ψ = −K²ψ）→ ẋ 线性
  • ② x × y　(kπ/2) sin 2πZ（cos²kX + sin²kX = 1，X 消掉）→ 恰好是 z 的花样 → ż 里 +xy
  • ③ x × z　kπ cos kX (sin 3πZ − sin πZ)：sin πZ 回 y → ẏ 里 −xz；sin 3πZ 不在三个模态里 → 扔掉 = 截断

“只留三项，为什么能自己闭合？扔掉了什么？”

② 是 z 非留不可的理由：x、y 一乘直接生出 z。不留 z，方程只剩线性部分，ρ > 1 时振幅指数增长，没有东西让它停；z 是非线性的刹车。

③ 是截断发生的唯一地方。被问到可现场验 ②：积化和差后含 cos 2kX 的项正好抵消，只剩 sin 2πZ。

截断就是扔掉 sin 3πZ；z 是非线性的刹车。

第 10、12 页 · 截断的代价

心算扔掉的 sin 3πZ 与留下的 −xz 同系数（③ 括号里两项）

留下的 −xz 比驱动 ρx = z/ρ；定常卷 C± 上 z = ρ − 1：

ρ = 1.1：0.1/1.1 ≈ 9%　　ρ = 28：27/28 ≈ 96%

传热：定常卷上 Nu = 1 + 2z/ρ = 3 − 2/ρ ≤ 3（ρ = 28 是 2.93）；真实对流 Nu 约 ∝ Ra1/3，无界

⇒ ρ = 28 时高阶模早被强烈激发：三行方程是自洽的数学对象，不是流体模型

刚过 ρ = 1，xz 是小量乘小量，扔掉的那块也小，截断有渐近依据；到 28，扔掉的强迫和驱动 ρx 同一量级，真实流体里 sin 3πZ 一定长起来。传热是第二个迹象：截断把 Nu 封顶在 3。

第 10 页一句带过：线性项只有驱动和扩散，非线性两项 −xz、xy 都是 u·∇θ，混沌全来自搬运。

恰好就是这组方程的装置：Malkus 水车、热虹吸环、单模激光（Haken 1975）。

后面的结论关于方程本身，不关于天气。

第 11 页 · 参数代入（时间紧就跳过）

Rac(a) = π⁴(1+a²)³/a²，a² = ½ 最小 → 27π⁴/4 ≈ 657.5

β = 4/(1 + ½) = 8/3，卷宽 √2 H　　σ = 10 > β + 1 = 11/3　　ρ = 28 > ρH ≈ 24.74

“为什么是 8/3 这么怪的数？”

8/3 是最先失稳的那种卷的几何；σ 和水同量级（室温约 7），还得大于 β + 1，否则 C± 永不失稳；28 刚过 24.74。量级（被问再说）：1 cm 水层上下差 1 K，Ra 约 1.5×10⁴；一个时间单位约一分钟；刚性板临界值是 1708。

8/3 是几何，10 是水，28 刚过失稳。

第 13 页 · 时间推进

Euler　u ← u + h f(u)　一阶

RK4　四个斜率加权：h 减半，误差 ÷ 2⁴ = 16

DOP853　8 阶，每步估局部误差，按 rtol 调 h；rtol = 1e−13 当参考解

“怎么让计算机往前走一步？”

左边代码就是全部计算：一个 f、一个循环。全篇实算只用 DOP853，只拧 rtol，开场演示就在拧它。过渡：方程有了，积分器也有了；谈误差之前，先看方程自己会做什么。

每一步都很准；问题是误差怎么累积。

第 16 页 · 不动点

板书ẋ = ẏ = ż = 0：y = x，z = x²/β，x(ρ − 1 − z) = 0

→ 原点 O；C± = (±√(β(ρ−1)), ±√(β(ρ−1)), ρ − 1)

心算ρ = 28：8/3 × 27 = 72，√72 ≈ 8.49 → C± = (±8.49, ±8.49, 27)

板书原点扔掉 xz、xy：λ = −β；λ² + (σ+1)λ + σ(1−ρ) = 0

两根之和 −(σ+1) < 0；两根之积 σ(1−ρ)：ρ > 1 变负 → 一正一负，鞍点

“刚才停下来的点，能不能不积分，直接从方程里找出来？”

O 是静止导热，C± 是定常卷，正负是转向；(x, y) → (−x, −y) 对称，所以成对。原点附近 xz、xy 是小量乘小量，扔掉就是线性化，z 自己分出去。ρ = Ra/Rac 这样归一化，就是为了让阈值落在 1。

ρ = 1，原点从稳定变成鞍点，C± 诞生。

第 17 页 · C± 的三次式与 Hopf

板书λ³ + a₂λ² + a₁λ + a₀ = 0

a₂ = σ+β+1，a₁ = β(σ+ρ)，a₀ = 2σβ(ρ−1)，ρ > 1 全正

全正 ⇒ 没有 λ ≥ 0 的实根 ⇒ 失稳只能一对复根从 ±iω 穿过：Hopf

代 λ = iω：虚部 ω² = a₁，实部 a₂ω² = a₀ ⇒ a₂a₁ = a₀

ρH = σ(σ+β+3)/(σ−β−1) = (10 × 47/3)/(19/3) = 470/19 ≈ 24.74

此时分解为 (λ + a₂)(λ² + a₁)：ω = √(8/3 × 34.74) ≈ 9.62，第三根 −a₂ = −41/3

“一直加热，定常卷什么时候站不住？”

系数全正挡住的只是实根：反例 λ³ + λ² + λ + 2，实根约 −1.35，三根之和 −1，复根实部 +0.18。根随 ρ 连续地动，到右半平面必须过虚轴；a₀ > 0，λ = 0 不是根，只能在 ±iω 成对穿。分母 σ − β − 1 说明为什么要 σ > β + 1。

亚临界：穿越时没有小极限环接住，轨道一离开 C± 就跳到远处的吸引子。

第一条：停不下，ρ = 28 时三个不动点全不稳。

三次式快速验算（ρ = 28）

心算a₂ = 41/3 ≈ 13.67　a₁ = 8/3 × 38 ≈ 101.3　a₀ = 160/3 × 27 = 1440

根：−13.85，0.094 ± 10.19i

  • ✓ 积 = −a₀：13.85 × (10.19² + 0.094²) ≈ 13.85 × 104 ≈ 1440
  • ✓ Routh–Hurwitz：a₂a₁ ≈ 1385 < a₀ = 1440，差 55 → 复根实部 > 0
  • ✓ 反推实部：a₂a₁ − a₀ = −2α[(r − α)² + ω²] → α ≈ 55 / (2 × 293) ≈ 0.094
  • ✓ 原点：λ² + 11λ − 270 = 0 → (−11 ± √1201)/2 = +11.83，−22.83；连 −β，和 −13.67 = tr J

ρ 每加 1，a₀ 涨 160/3 ≈ 53，a₂a₁ 只涨 41/3 × 8/3 ≈ 36，所以一过 ρH 就一直是 a₀ 大。

“三个不动点都站不住，轨道在两叶之间怎么换？”

近邻每圈乘 |F′| > 1；“乘多少”变成一个数就是 Lyapunov 指数，要算它先在任意一点线性化（下一页）。

三维的流压成一条一维映射，映射处处拉伸。

4

Jacobian 与 Lyapunov 指数

① · 第 19–23 页 · 7 分钟右栏写下第二、三条
第 19 页 · 左栏，方程下面

板书δu̇ = J(u) δu，Jij = ∂fi/∂uj 　J =−σσ0ρ − z−1−xyx−β

逐行：σ(y−x) → −σ, σ, 0；xρ − xz − y → ρ−z, −1, −x；xy − βz → y, x, −β

读三次：不动点上常数 → 特征值（板块 2，代 0 即原点矩阵）· 对角线 tr J 与点无关 · 沿轨道每点不同 → 局部指数、QR

“轨道上任意一点旁边差一点点，这一点点下一刻怎么变？”

J 的第 i 行回答：第 i 个变量的变化率对 x、y、z 各多敏感。线性项求导得常数，xz、xy 求导留下 x、y、z，所以轨道走到哪 J 就是哪个矩阵。

J 里有 x、y、z，所以它随轨道上的点变。

第 20 页 · 局部指数

板书d/dt ln|δu| = e·J e，e = δu/|δu|

例：J = [0 1; 0 0]（剪切），特征值 0, 0；e = (1, 1)/√2 → e·J e = ½ > 0

Lorenz 沿吸引子：平均 0.907 = λ₁，标准差 4.25，51% 的时刻 < 0；J 最大实部特征值平均 1.65 ≠ λ₁

“轨道走到这一点，扰动在这里长得多快？”

|δu|² 求导得 2δu·Jδu，除以 2|δu|² 就是 e·Je。只给一个点不够，还要说扰动指向哪。特征值说“一直乘同一个矩阵，最后谁赢”；e·Je 说“此刻这个方向怎样”。下一刻矩阵换了，本征方向也换了。

窗口 τ 上平均 = 有限时间指数：τ = 0.5 标准差 2.60，43% 的窗口在缩；τ → ∞ 收拢到 λ₁。图上红色在两叶交界与外缘。

局部指数随点、随方向跳，只有长期平均才是 λ₁。

第 21–22 页 · 定义与 QR

板书λ = lim (1/t) ln(|M(t)δu₀| / |δu₀|)，M′ = JM，M(0) = I

线段 eλ₁t　面积 e(λ₁+λ₂)t　体积 e(λ₁+λ₂+λ₃)t

板书例：每步乘 diag(2, ½)，λ = ±ln 2

v₁ = (1, 0) → (2ⁿ, 0)；v₂ = (1, 1) → (2ⁿ, 2⁻ⁿ)，长度 ≈ 2ⁿ，又量到 +ln 2

夹角 ≈ 4⁻ⁿ（n = 10 → 10⁻⁶）；减掉 v₁ 方向 → (0, 2⁻ⁿ)，−ln 2 出来：这一步就是 Gram–Schmidt，即 QR

λk = (1/(nΔt)) Σ ln|Rkk| = ⟨qk·J qk⟩，Δt = 1

“J 在不动点上看特征值就行，沿着轨道为什么不行？”

每走 Δt 乘一次 I + J(u)Δt，沿轨道是一长串各不相同的矩阵，没有共用的本征方向。随手跟三个向量，全倒向 λ₁：第 22 页不做 QR，t = 30 时夹角 3×10⁻¹⁴（心算 e−(λ₁−λ₂)t = e−30 ≈ 10⁻¹³），三条斜率 0.98 / 1.01 / 1.05 全是 λ₁；做 QR 后分开成 0.92 / −0.003 / −14.58。

为什么每 Δt = 1 就做：夹角到 10⁻¹⁶ 就丢，ln(10¹⁶)/0.9 ≈ 41，和双精度预报极限是同一个数；长度到 e709 溢出。

第二条：一个方向在拉伸，λ₁ ≈ 0.9。

第 23 页 · 迹

板书Σ qk·J qk = tr(QᵀJQ) = tr J = −(σ+1+β) = −41/3 ≈ −13.67，每一瞬间

λ = (+0.904, 0, −14.57)：λ₂ = 0 沿流方向；λ₃ = −13.67 − 0.90 = −14.57

心算DKY = 2 + 0.904/14.57 ≈ 2.06；体积每个时间单位乘 e−13.67 ≈ 10⁻⁶；实测 Σλ − tr J = 2×10⁻⁹，不拟合

回扣截面一圈 0.75：0.9 × 0.75 ≈ 0.68，e0.68 ≈ 2 → 映射每圈把近邻拉开约 2 倍

“三个指数加起来是多少？能不能不算？”

换一组正交坐标轴不改迹。Lorenz 特殊在对角线 −σ、−1、−β 是粘性和两项热扩散，没有变量：搬运只挪体积，耗散才缩体积。和式守的是变分方程、积分精度、QR 记账；三个数怎么分它管不到，λ₁ 单独的依据是第 26 页系综斜率 0.875。

回扣那一行是 Abramov 公式：截面映射的指数 = λ₁ × 平均回归时间；拿 fig14 的截面数据拟合局部斜率核过，平均 ln|F′| = 0.68。停不下、跑不掉（备用 2）、体积为零 → 奇怪吸引子。

第三条：体积缩到零，Σλ = tr J = −13.67。
