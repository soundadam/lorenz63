背景

这组方程描述的是什么？

先不谈数值，花几分钟让 x、y、z 和 σ、ρ、β 都有一个看得见的物理意思。

背景 · 方程从哪里来

一层从下面加热的流体

底下的流体受热变轻想上浮，上面的冷流体想下沉。粘性和热扩散会抵抗这种翻动。

两股力量之比叫 Rayleigh 数：

$$\mathrm{Ra} = \frac{g\,\alpha\,\Delta T\,H^3}{\nu\,\kappa} = \frac{\text{浮力}}{\text{粘性}\times\text{热扩散}}$$
  • Ra 小于临界值 Rac：流体静止，热量只靠传导
  • Ra 大于 Rac：静止失稳，长出一排对流卷
  • 另一个无量纲数 Pr = ν/κ：动量与热量各自扩散的快慢之比

Saltzman（1962）、Lorenz（1963）研究的就是这个 Rayleigh–Bénard 问题，只看一个方向上的二维卷。

先讲一个能想象的东西：锅里的水从下面加热。g 是重力加速度，α 是热膨胀系数，ν 是运动粘度，κ 是热扩散率，H 是层厚。

Boussinesq 近似下，二维流动用流函数 ψ 和温度偏离线性剖面的部分 θ 写成两条偏微分方程（Lorenz 1963 式 17–18）：涡量方程里浮力 gα∂θ/∂x 驱动、ν∇⁴ψ 耗散；温度方程里流体把背景温度梯度往上搬、κ∇²θ 抹平，两条都有平流项 J(ψ,·)。这是无穷维的系统。

背景 · 方程从哪里来

x、y、z 是三种空间花样的振幅

Lorenz 把流函数和温度各展开成 Fourier 级数，只留三项：

$$\psi \propto x\,\sin\tfrac{\pi a X}{H}\sin\tfrac{\pi Z}{H}$$ $$\theta \propto y\,\cos\tfrac{\pi a X}{H}\sin\tfrac{\pi Z}{H} - z\,\sin\tfrac{2\pi Z}{H}$$
  • x：卷翻滚得多快，正负是转向
  • y：上升流与下沉流之间的温差
  • z：平均温度剖面弯离直线的程度，也就是对流额外运走的热：Nu = 1 + 2z/ρ

这里大写 X、Z 是空间坐标，小写 x、y、z 是 Lorenz 变量，别混。a 是卷的水平波数。比例系数和时间单位在报告 §1.2 里写全了。

看图：左上是 x 单独的样子，就是一对反向旋转的卷；中上是 y，左右边缘热、中间冷；右上是 z，水平均匀，只改竖直剖面，靠近上下板变陡、中间变平。下面是三者在不动点 C+ 合起来的样子：热流体在两边升起，冷流体在中间沉下，一对定常卷。

Nu 是 Nusselt 数，实际热流与纯传导热流之比。所以 z 有个很直接的读法：它就是这层流体在多大程度上靠对流在运热。

代回去，每一项都是一个物理过程

方程项物理过程
\(\dot x = \sigma(y - x)\)\(+\sigma y\)浮力：热的一侧轻、冷的一侧重，温差推着卷转
\(-\sigma x\)粘性给翻滚刹车
\(\dot y = \rho x - y - xz\)\(+\rho x\)卷把底部热流体搬上去、顶部冷流体搬下来，制造水平温差
\(-y\)热扩散把水平温差抹平
\(-xz\)剖面中段已被拉平，同样的翻滚搬来的温差打了折扣
\(\dot z = xy - \beta z\)\(+xy\)热的上升、冷的下沉，净效果是向上运热，把剖面拉弯
\(-\beta z\)热扩散把剖面拉回直线

非线性只有标色的两项，都来自流体搬运温度（平流 u·∇θ）。时间以热扩散为单位，Lorenz 的 1 个时间单位约等于 H²/κ 的 1/15。

这一页是想让方程不再是三个抽象的字母：线性项都是"驱动"或"扩散"，非线性项都是"搬运"。

ρx 那一项里的 ρ 就是 Ra/Ra_c：背景温度梯度越陡，同样的翻滚搬出的温差越大，所以 ρ 是驱动强度的旋钮。

时间单位：τ = π²(1+a²)κt/H²，a² = 1/2 时系数约 14.8。量级感：1 cm 厚的水层 H²/κ 约 700 秒，一个 Lorenz 时间单位约一分钟。

背景 · 方程从哪里来

经典的那一组数，每个都有来由

σ = 10Prandtl 数 ν/κ
β = 8/3卷的几何：4/(1+a²)
ρ = 28Ra / Rac
  • β = 8/3：宽度不同的卷各有各的失稳阈值 \(\mathrm{Ra}_c(a) = \pi^4(1+a^2)^3/a^2\)，在 a² = 1/2 最低（27π⁴/4 ≈ 657.5）。取最先失稳的那种卷，β = 4/(1 + ½) = 8/3，卷宽 √2 H。
  • σ = 10：和水同一量级（室温约 7）。它还得大于 β + 1 = 11/3，否则 C± 永远不会失稳，就没有后面的混沌。
  • ρ = 28：Ra 是临界值的 28 倍。ρ 超过 \(\rho_H = \sigma(\sigma+\beta+3)/(\sigma-\beta-1) = 470/19 \approx 24.74\) 时 C± 失稳；Lorenz 取了一个稍高于它的整数。

三个数都出自 Lorenz 1963 原文，此后的文献几乎都沿用，后面所有实验也都用这一组。ρ_H 在 ① 里会再出现。

经常有人问"为什么是 8/3 这么怪的数"。答案是几何：它对应最容易被激发的那种卷的宽高比。Ra_c 那个公式是上下自由滑移边界的线性稳定性结果，仓库里有测试对它求最小值，检查恰好得到 β = 8/3。

σ 的条件 σ > β+1 来自 ρ_H 分母：分母非正时没有 Hopf 分岔。

量级感（粗略，用室温水的物性）：1 cm 水层上下温差 1 K，Ra 约 1.5×10⁴，是自由边界临界值 657 的二十多倍；真实刚性板的临界值是 1708，倍数要小一些。

背景 · 方程从哪里来

推导到这里就断了

局限三模截断只在 ρ 略大于 1 时有渐近依据。ρ = 28 时被丢掉的高阶模态早已被激发，它是一个自洽的数学对象，不再是流体模型。

后面所有结论都关于这个数学对象，不涉及流体或天气的主张。

但有几个物理系统，化简后恰好就是这组方程：

  • Malkus 水车：x 是转速，y、z 是桶中水量分布的一阶 Fourier 系数
  • 热虹吸环：竖直圆环管里的对流，x 是环流速度
  • 单模激光（Haken 1975）：x 是光场，y 是极化，z 是粒子数反转

很多科普会说"Lorenz 方程描述大气对流，所以天气不可预报"。正确的说法要弱得多：它展示了低维确定性系统也能有敏感依赖。这个定性教训可以迁移到大气，方程本身不能。

右边几个系统是给"有没有一个物理量对应"的回答：对流里这种对应只在近阈值成立，而在水车、热虹吸环、激光里，变量重新标度后方程是精确的，只是 σ、β、ρ 换成那些装置自己的参数。

第 ① 问

能像检查能量守恒那样检查它吗？

学数值方法时最常用的验证是看守恒量漂不漂。这一段先看 ρ 变大时相图怎么变，再说明 Lorenz 为什么没有这样的量可查。

① 没有不变量可查

四个区间，四种相图

  • ρ = 0.5　只有原点，全局稳定。
  • ρ = 10　原点成鞍点，轨道以衰减螺旋落向 C±。
  • ρ = 24.5　C± 仍线性稳定，混沌吸引子已经存在。终点取决于吸引域。
  • ρ = 28　三个不动点全不稳定，蝴蝶出现。

这四格不丢瞬态：要看的就是轨道怎样落到吸引集上。

实心点稳定，空心点不稳定。ρ=24.5 这一格最有意思：蓝色轨道在两叶间游荡，绿色被困在 C+ 附近的小环里。这是亚临界 Hopf 的典型后果，在失稳阈值之下就已经有另一个吸引集。

其他所有图都先积 50 个时间单位再记录，只有这页保留瞬态。

① 没有不变量可查

三个不动点，ρ = 28 时全部不稳定

$$C_\pm = \left(\pm\sqrt{\beta(\rho-1)},\ \pm\sqrt{\beta(\rho-1)},\ \rho-1\right)$$

= (±8.4853, ±8.4853, 27)

亚临界 Hopf 阈值有闭式：

$$\rho_H = \frac{\sigma(\sigma+\beta+3)}{\sigma-\beta-1} = 24.737$$

这张图是纯线性代数，不含任何积分：对每个 ρ 解析写出 C+，算 Jacobian 特征值，取实部最大者，它在 ρ_H 处穿零。

ρ = 28 在 ρ_H 右侧：三个不动点全不稳定，没有稳态可去。轨道停不下也跑不掉，只能在有界区域里永远游荡。

① 没有不变量可查

耗散，但有界

$$V = \rho x^2 + \sigma y^2 + \sigma (z-2\rho)^2$$ $$\frac{\mathrm dV}{\mathrm dt} = -2\sigma\left[\rho x^2 + y^2 + \beta(z-\rho)^2 - \beta\rho^2\right]$$

方括号在椭球 \(\rho x^2 + y^2 + \beta(z-\rho)^2 = \beta\rho^2\) 之外为正，V 在那里单调下降。

所有轨道最终被困在一个有界区域里。

局部指数分离 + 全局折叠回来
这是混沌，不是发散。

耗散不等于收缩到一点，也不等于跑到无穷。上一页说明轨道停不下来；这个 Lyapunov 函数说明它也跑不掉。两者合起来就是奇怪吸引子。

① 没有不变量可查

相空间体积以固定速率坍缩

Jacobian 的迹在任何一点都相同：

$$\operatorname{tr} J = -(\sigma+1+\beta) = -13.667$$
−13.6675拟合斜率
6.1e−5相对误差
谐振子贴在 0 上：辛结构保面积。Lorenz 没有守恒量、没有辛形式，"该用辛方法吗"在这里是个空问题。

由 Liouville 公式，体积按 e^(−13.667 t) 收缩，2 个时间单位缩到 1.35×10⁻¹²。验证方法：积分 M′ = JM，M(0)=I，det M 就是体积因子。

这一页就是第 ① 问的答案：守恒系统可以监视能量、监视不变量，Lorenz 连出发点都没有。

③ 统计量不随求解器变

那还剩下什么可信？

直觉：局部误差很小的数值轨道，虽然不是你要的那条真解，可能紧跟着另一条初值稍有不同的真解。

那么画出来的蝴蝶是真的蝴蝶，只是不是"你那只"。

对一致双曲系统，这是定理（影随引理）。

局限Lorenz 吸引子含有原点这个不动点，不是一致双曲的，严格的影随引理不适用。Tucker 2002 用计算机辅助证明它是奇异双曲吸引子，数值影随的结果多是有限时间、逐案验证的。

影随只提示方向。真正的辩护必须可测量。

Tucker 2002 解决的是 Smale 第 14 问题：证明 Lorenz 吸引子存在且结构稳定。

可能被问："能不能直接把数值轨道修正成真轨道看看？" 回答：可以做多重打靶 + Newton 的有限时间影随实验，目前列在待补清单里。

③ 统计量不随求解器变

教科书上的蝴蝶不是幻觉

红点是三个不动点：原点是鞍点，C± 各自是一叶的中心。

两叶间的切换是非周期的，而切换序列正是 Lorenz 映射编码的东西。

可信的是这个形状和它的统计，不是其中任何一条轨道。

喘口气的一页。把第 ③ 问收成一句话：蝴蝶是真的，可信的是它的形状和统计。

④ 判据随系统类型变

"可信吗"不能脱离系统类型回答

系统类型可保的结构验证手段长时间单条轨道
保守（哈密顿）辛形式、不变量能量有界？辛 / 分裂格式可信（误差多项式增长，辛格式下线性）
耗散、非混沌收敛到吸引子是否收敛到正确的稳态或极限环可信
混沌无统计量对方法不敏感？不可信（超过 1/λ₁ 量级）

混沌问题的验证协议：容差扫几个数量级、方法换几种，检查 λ₁、不变密度、Lorenz 映射是否稳定。第 ③ 问就是在执行这套协议。

第一行是分子动力学、天体力学的世界：H = T(p) + V(q) 可分离，于是有显式辛格式（Verlet、蛙跳、Yoshida 高阶复合），验证手段是监视能量有界震荡不漂移。

第一行在这个仓库里有对照实验，就是下一页。

④ 判据随系统类型变

守恒系统里，精度换来成倍的时间

7.4×10⁻⁴Verlet 能量误差，1000 周期不涨
第 33 周期RK4 能量误差超过 Verlet
斜率 2.0 / 2.5可信时间对代价是幂律

RK4 每步算四次力、Verlet 一次，所以取 h_RK4 = 4 h_Verlet，代价相同。偏心率 0.6，Hairer–Lubich–Wanner 书里的标准例子。

(a) 能量：Verlet 有界震荡，RK4 线性漂移。Verlet 的角动量漂移 8×10⁻¹⁴，中心力下精确守恒。(b) 位置误差：Verlet ∝ t，RK4 趋向 ∝ t²；两者最后都饱和在轨道长轴 2，相位丢了，轨道形状还在。

(c) 要老实讲：RK4 的线在 Verlet 上面，同等代价下四阶方法的相位反而保持得更久。辛格式买到的不是更准，而是不漂，跑得越久越占优。对论点要紧的是两条线都是幂律：步长减半，Verlet 的可信时间翻四倍。对照图 9 的 Lorenz，8 个数量级只换来 20 个时间单位。

可能被问："那 Verlet 到底好在哪？" 回答：能量和角动量不漂，所以轨道的形状永远对；误差是线性而不是平方增长，时间够长它一定反超。

④ 判据随系统类型变

回到声学

表的第一行

无耗散波动方程是哈密顿系统。Yee 的 FDTD 格式里 E 与 H 在时间上交错半格，那就是蛙跳格式，也就是辛积分器。

FDTD 能长时间运行而不出现数值能量爆炸或人工衰减，原因在结构。

表的第三行

非线性声学、声致湍流一旦进入混沌，单次实现的波形不该当作可复现的预报。

该报告的是谱、相关函数、统计矩。

把结论连回课程本身。左边对应判据表的保守行，右边对应混沌行。

结论

守恒系统看不变量，混沌系统看统计量

  • Lorenz 没有守恒量，体积以 tr J = −13.667 坍缩。
  • 可预报时间被 λ₁ = 0.904 锁死在约 41 个时间单位，精度只换来对数的时间。
  • Lyapunov 谱、不变密度、Lorenz 映射对求解器不敏感。

    备用 · ① 没有不变量可查

    三维流 → 二维截面 → 一维映射

    3992T = 3000 内上行穿越 z = 27 的次数
    56.7%穿越后留在同一叶

    截面上是两条细线，不是一片云。回归映射处处 |F′| > 1，任何不动点都不可能稳定。

    截面取在 C± 的高度 z = ρ−1 = 27。中间一格的两条细线，就是 Kaplan–Yorke 维数 2.06 的几何含义：横向厚度小到在这个尺度上看不见。

    备用 · ② 精度只换来对数时间

    两件常被混为一谈的事

    是什么的性质由什么决定步长能改变吗
    数值稳定性方法 + 步长hλJ 是否落在稳定域内能
    Lyapunov 指数流本身方程不能

    真解自己就在指数分离。步长变小只减少注入的误差量，这些误差随后照样按 eλt 放大。

    被问到"步长再小一点不就行了"时用这一页和下一页。混淆这两件事会让人以为只要步长够小就能一直跟住轨道。

    备用 · ② 精度只换来对数时间

    瓶颈是精度，不是稳定性

    0.1253RK4 稳定步长上限
    ≈ 0.01实际用的步长

    吸引子上采样的 Jacobian 谱：max |λJ| = 23.0，36.3% 的特征值实部为正。

    小心红点（增长模）永远在稳定域外。那是格式在复现真实的增长方向。要求全谱 |R(hλ)| ≤ 1 只会得到 h = 0。稳定域只约束衰减模。

    左图 h=0.01：整个谱缩在原点附近，离边界还有一个数量级。右图 h=0.1253：衰减模正好顶到边界。经典估计 2.785/|min Re λ_J| = 0.1275，一致。

    "我得限制 h 免得它炸掉"：动作对，理由错。这一条有测试守着：test_stability.py::test_expanding_modes_do_not_veto_every_step。

    备用 · ② 精度只换来对数时间

    Lyapunov 谱为什么必须重正交

    3×10⁻¹⁴不做 QR，t = 30 时切向量夹角（弧度）
    0.98 / 1.01 / 1.05不做 QR：三个"指数"全是 λ₁
    0.92 / −0.003 / −14.58做 QR 后分开

    做法：沿轨道积分变分方程 Q′ = J(u)Q，带着三个切向量走，每隔一小段做 QR，把 log|R_ii| 累加。

    不做 QR：任何一般向量都含最不稳定方向的分量，按 e^(λ₁t) 长，于是三个向量都倒向同一条线，λ₂、λ₃ 一点痕迹都没有。QR 每次把第 k 个向量投影到前 k−1 个的正交补上，是唯一让它们可见的机制。

    附带好处：不归一化的话 e^1800 早就溢出了。右格是 T=200 的短跑，和下一页 T=2000 的谱在第二位小数上一致。

    备用 · ② 精度只换来对数时间

    λ₁ 是数值结果，凭什么信它

    λ = (+0.903764, −0.000411, −14.570019)

    对任何流 \(\sum_i \lambda_i = \langle \operatorname{tr} J\rangle\)，而 Lorenz 的 tr J 是常数。不需要拟合：

    Σλᵢ　　= −13.666666669
    tr J　　= −13.666666667
    偏差　　= 2.17e−09

    DKY = 2 + λ₁/|λ₃| = 2.062：体积为零，却比曲面厚。

    Benettin 算法，T = 2000。λ₂ ≈ 0 是应该的：有界非定常流沿流方向总有一个零指数。

    如果变分方程写错、QR 记账错、或者积分精度不够，这个和会明显偏掉。它对得上，λ₁ 就有了"看起来合理"之外的依据。这个恒等式就是测试 test_lyapunov.py::test_spectrum_sums_to_the_divergence 的断言。
